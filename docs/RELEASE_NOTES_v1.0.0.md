# Release v1.0.0

## Initial public release

This release packages the ESP32-based LPG Security System prototype as a reproducible open-source project.

### Included

- ESP32 firmware for MQ-6, DHT11, and flame monitoring
- Local emergency control for relay, fan, servo, buzzer, and LEDs
- 0.96-inch I2C OLED monitoring
- Blynk telemetry and `lpg_emergency` notification event
- Single-BC547 relay interface documentation
- MQ-6 ADC voltage-divider guidance
- System architecture diagram
- Detailed flowchart
- Circuit diagram and circuit notes
- Staged hardware testing guide
- Research-style technical report
- Credential-safe `config.h.example` and `.gitignore`
- MIT License

### Important

This is an academic/educational prototype and is not a certified LPG or fire-safety product. Experimental measurements and real hardware photographs are intentionally kept separate from this initial source release and can be added as the prototype is tested.
